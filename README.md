# Solar-Powered-Boost-Converter-for-Lithium-Ion-Battery-Charging
This project explores the design, simulation, and implementation of a solar-powered boost converter system aimed at efficiently charging lithium-ion batteries using a 4V solar panel. It integrates renewable energy principles with practical circuit design and real-world testing.

## 🔧 Features

- Boost converter design with MPPT (Maximum Power Point Tracking)
- LTSpice simulation for voltage output and efficiency
- Hardware prototype with real-time light-based solar charging
- Safety mechanisms including voltage and thermal monitoring

- LTSpice simulation showed stable 20V output from the boost converter
- Physical hardware responded positively to light exposure, confirming voltage gain
- Efficient and safe battery charging achieved under test conditions
